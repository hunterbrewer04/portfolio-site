Speedtest CLI makes Ookla's official internet speed test nicer to run from the terminal. You get live progress bars while it tests, a clean summary at the end, and simple output modes when a script needs the numbers instead of a person.

## What it does

- Shows live progress for ping, download, and upload, then a tidy summary of your results.
- Prints one line, clean JSON, or Ookla's full result for scripts and automations.

## Notes

- Uses Ookla's real speed test under the hood, so the numbers match speedtest.net.
- Small on purpose: about 300 lines of Python with nothing else to install.
