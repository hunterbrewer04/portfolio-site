Web Stack is the part of my AI setup that lets agents search the web and read pages in full. It runs on my home server, and instead of paying a search API for short snippets, my agents get the whole page, using the cheapest method that actually works for that site.

<FlowDiagram id="web-stack-search" />

<FlowDiagram id="web-stack-read" />

## What it does

- Searches the web through a private, self-hosted search engine, with a paid fallback only when it's needed.
- Reads a page with a fast text extractor first, and only steps up to a full browser when a site needs one.
- Works with both of the agent tools I use day to day, so they share one web layer.

## Notes

- Built to be private: it never stores the searches my agents run.
- It's polite to the sites it visits, following their crawling rules and pacing its requests.
- It's checked by a test suite that runs real pages through it, so a change that breaks reading shows up before it ships.
