Repo Graph Viewer turns a codebase into a map you can explore. Every function, class, and file becomes a dot, every call or import becomes a line, and related code naturally clusters together in its own color, so you can see the shape of a project at a glance.

The frame above is the real app running on this portfolio's own code. Pick another example from the header, or drop in your own.

## What it does

- Shows any codebase as an interactive 2D map or a 3D view. Press `G` to switch.
- Hover a dot to light up everything it connects to, or click it to step through the code one link at a time.
- Search by name to find any part of the project instantly.

## Notes

- Runs entirely in the browser, with no server behind it.
- The heavy 3D view only loads when you ask for it, so the page stays quick.
- Works on phones too, with a detail panel that slides up from the bottom.
