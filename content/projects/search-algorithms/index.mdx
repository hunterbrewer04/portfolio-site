The Search Algorithms Visualizer shows how classic AI search algorithms find their way through a problem. Pick an algorithm, press play, and watch it explore step by step until it finds a path. The frame above is the real thing, running in the page.

## What it does

- Eight algorithms, from breadth-first search to A*, on the same problems so you can compare them.
- Three views: a maze-like grid you can draw on, a map of connected cities, and the search tree itself.
- Race mode runs all eight side by side on one board.

## Notes

- Switches for the details that textbooks disagree on, so you can see how each one changes the result.
- Every algorithm is checked against a known-correct answer across hundreds of random boards.
- No setup at all: it's plain web code that runs straight in the browser.
