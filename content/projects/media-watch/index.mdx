Media Watch gives AI agents a way to watch video. Agents are usually blind to it. The common workaround of grabbing a handful of still frames throws away speech, music, motion, and everything that happens between frames. Media Watch sends the entire clip, audio included, to a model that natively understands video, and hands back a structured report the agent can reason over: what happens and when, what's written on screen, what's said, and what it sounds like.

```text
$ mw watch "https://www.instagram.com/reel/…" -q "what's the recipe?"
[instagram] Crispy chili oil noodles  ·  42.3s  ·  google/gemini-3.8-flash  ·  $0.0061
A creator makes chili oil noodles in one pan, narrating each step over upbeat music…
Answer: Boil noodles, then pour hot oil over garlic, chili flakes, sesame and soy sauce…
```

## Three ways to use it

- **A Hermes Agent plugin** that adds a `watch_video` tool, so you can paste a link into a chat with your agent and ask about it.
- **A standalone CLI**, `mw watch` and `mw stats`, for scripts, debugging, or any other agent framework.
- **A plain Python library.** The core deliberately has no Hermes imports and depends only on `httpx` and `pydantic`; the plugin is a thin layer that injects Hermes' profile-aware secret lookup into the same `watch()` call.

## Engineering details worth noting

- **Size math built around the model's limit.** The proxy is capped at 14 MiB because base64 inflates it by a third, landing at ~19 MB, just under Gemini's ~20 MB inline request limit. If a 480p, 15 fps encode is still too big, ffmpeg re-encodes at progressively higher CRF until it fits, and a test asserts the budget math directly.
- **Fallback only when it can help.** A failed call falls back to a different model, except for a bad key, exhausted credits, a forbidden request, or a too-large payload: errors where switching models can't change the outcome.
- **Honest cost accounting.** Every paid attempt is logged to SQLite with OpenRouter's own reported cost, including failed retries and the failed primary before a fallback, so `mw stats` reflects what was actually spent.
- **Two careful cache layers.** Downloads are keyed by the canonical URL with tracking parameters stripped (or by path, size, mtime, and head/tail bytes for local files); reports are keyed by prompt version, model, and normalized question. A fallback model's answer is never cached under the primary model's key.
- **Strict structured output, checked twice.** The JSON schema is sent with `strict: true`, OpenRouter is told to route only to providers that support it, and the response is validated again with Pydantic, with a test proving the schema and the model can't drift apart.
- **Prompt-injection aware.** The post title is treated as context only ("trust what you see"), and the plugin labels the whole report as untrusted content so the agent never follows instructions hidden in a video.
- **Hermetic tests and secret-scanning CI.** No real footage lives in the repo: ffmpeg generates a synthetic test clip, OpenRouter is mocked with `httpx.MockTransport`, and CI runs gitleaks, ruff, and 40 pytest cases on every push.
