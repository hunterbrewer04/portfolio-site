Clean TV replaces the ad-filled Google TV home screen with a quiet one. It is a single 115 KB Kotlin app: a clock and greeting over a grid of the apps you actually installed, an inputs menu, and a screensaver. Next to it ships a set of ADB scripts that hand the Home button over to Clean TV and switch off the preinstalled apps the TV came with, one batch at a time, with a single command to undo all of it.

Every screenshot here is real, pulled from a TCL Google TV over ADB. The signed APK is on [GitHub Releases](https://github.com/hunterbrewer04/clean-tv/releases/latest).

## What it does

- **No ads, no tracking, no network.** No third-party runtime libraries. The only permission it asks for opens the system's own "Uninstall?" dialog.
- **Your apps, your order.** Hold OK on any tile to move it, or to uninstall it if you installed it yourself. New installs show up right away.
- **Inputs built at runtime.** The menu lists whatever HDMI, AV, and tuner sources the TV reports, with nothing hardcoded per model.
- **Lighter than stock.** About 55 to 75 MB of RAM in use, against about 150 MB for the stock home screen on the same TV.

Streaming logins, Chromecast, AirPlay, Bluetooth remotes, and the Play Store all keep working. The scripts refuse to touch the packages behind them.

## How the scripts work

```bash
TV=192.168.1.50 scripts/survey.sh                                    # read-only baseline
TV=192.168.1.50 APPLY=1 APK=clean-tv-v0.5.4.apk scripts/install.sh  # installs alongside stock
```

1. **Survey** the TV with a read-only script that saves a baseline.
2. **Install** the launcher next to the stock home screen and try it out.
3. **Hand Home over** to Clean TV, then disable bloat one batch at a time.
4. **Undo** whenever you want with `restore.sh`. Nothing is ever uninstalled.

## Decisions worth knowing

- **Dry run by default.** Every script that changes the TV only prints what it would do until you add `APPLY=1`.
- **Brand profiles, not a hardcoded list.** Which packages are safe to disable differs by brand, so that lives in small profile files (`google`, `hisense`, `tcl`). Any other brand gets the `google` baseline, which only touches packages that are the same on every TV.
- **Protected packages are enforced on every write**, not just listed in docs, so a bad profile can't disable the remote, casting, or the TV's inputs.
- **The remote's app buttons still work.** With the stock launcher off, the Netflix and YouTube keys go dead. An optional accessibility service brings them back.
- **Released like a real app.** Signed APKs on GitHub Releases, a changelog, and CI that runs unit tests, Android lint, a release build, and shellcheck on every push.
